# User Guide / उपयोगकर्ता गाइड

## Student (English)
1. Register and sign in.
2. Browse approved events.
3. Open an event and register. If it has a fee, enter the UPI/payment reference after paying through the college's instructed channel.
4. Open Dashboard → registration → QR pass.
5. Present the QR pass at the event. The organizer/admin marks attendance.
6. After attendance is confirmed, print or save the certificate as PDF.

## विद्यार्थी (हिन्दी)
1. Register पेज से अपना account बनाएं और Login करें।
2. Events पेज पर उपलब्ध approved events देखें।
3. Event खोलकर Register करें। यदि fee है, तो कॉलेज द्वारा बताए गए तरीके से भुगतान करने के बाद UPI/payment reference डालें।
4. Dashboard में अपनी registration खोलकर QR pass दिखाएं।
5. कार्यक्रम में QR pass दिखाएं। Admin/आयोजक attendance mark करेगा।
6. Attendance confirm होने के बाद certificate को Print या PDF में Save करें।

## Admin (English)
1. Register a normal account, then promote it to admin using the SQL command in README.
2. Sign in and open Admin.
3. Approve/reject student event proposals.
4. Verify payment references only after checking the actual payment.
5. Mark attendance after checking the attendee at the venue.

## Admin (हिन्दी)
1. पहले सामान्य account बनाएं, फिर README में दिए SQL command से role को admin करें।
2. Login करके Admin पैनल खोलें।
3. Student के event proposals को approve/reject करें।
4. वास्तविक भुगतान जांचने के बाद ही payment verify करें।
5. कार्यक्रम स्थल पर उपस्थिति जांचकर attendance mark करें।
